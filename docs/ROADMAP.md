# Product Roadmap

## Version 1 — Included

- Authentication
- Roles
- Catalog
- Member registration
- Issue / return / renew
- Overdue and fine calculation
- Dashboard
- REST API
- Seed data
- Tests
- Docker

## Version 2 — Suggested

- Cover image upload
- Barcode / QR scanning
- Email due-date reminders
- Reservation / waitlist workflow
- Advanced analytics
- Export to CSV / Excel
- Bulk import from CSV
- Fine payment records
- Notification center

## Version 3 — Institutional

- PostgreSQL
- Redis-backed background jobs
- SSO / OAuth
- Multi-branch inventory
- Fine-grained permissions
- Full audit reporting
- Backup and disaster recovery
- Observability with structured logging
